# 📚 مستودع مقالات ودراسات السوق العقاري (Market Articles Repository)

ضع هنا أي مقالات، دراسات، تجارب سكان، أو منشورات مجموعات ملاك ترغب في استخلاص الخبرات منها لبوت سكنى.

### 📝 طرق مشاركة المقالات:
1. **نص مباشر في المحادثة:** يمكنك نسخ المقال أو الرابط وإرساله لي هنا مباشرة في الشات وسأقوم بتحليله وتضمينه في العقل العقاري للبوت.
2. **ملفات في هذا المجلد:** يمكنك وضع ملفات نصية (`.txt` أو `.md`) أو ملفات PDF بداخل هذا المجلد (`docs/articles/`) وسأقوم بقراءتها وتفريغها تلقائياً.

### 🎯 العناصر التي يتم استخلاصها من كل مقال:
* عيوب ومشاكل المنطقة أو المشروع الخفية.
* مميزات وتفضيلات المشترين في هذه المنطقة.
* أسعار المتر الحقيقية كاش وتقسيط.
* موثوقية المطور أو الكمبوند والتزامه بالصيانة.
